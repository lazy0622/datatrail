# DataTrail 时间口径合同（2026-11-11）

有日期范围但没有明确按下单还是送达日期归属的问题，需要先获得用户确认。
已交付是订单状态，不自动等于按送达日期统计。用户明确指定口径时不重复询问；
取消、超时或未回答不会自动采用默认口径，同轮也不会重复弹出时间确认。

范围限定为 olist_ecommerce_demo 的普通 Agent 链路，且启用
DATATRAIL_GRAIN_GUARD。查询和原生图表执行入口共用审查，确认信息从实际
question 回复绑定。错误时间字段的日期筛选在执行前返回结构化反馈，供模型改写。

验证：commerce_audit、dashboard SQL、安全、question 合同和只读工具相关测试
合计 180 passed。相关新文件和 question.py 的 Ruff 检查通过。
本地真实应用 SSE 冒烟中，模型询问一次，测试客户端通过真实回复接口选择下单时间，
最终返回 2018 年 7 月已交付订单 6,159 笔、商品金额 867,953.46，耗时 14.17 秒。
该请求明确限制使用 question/sql_query，属于受控集成验证，不是留出集准确率。
完整本地记录在忽略目录 output/datatrail/time-contract-live-nov11.json。

实现使用有限的中文/ISO 日期标记和 SQLGlot 日期字面量筛选检查，不保证理解任意
自然语言、CTE 别名、时区或所有 SQL 时间表达式。下单与送达两种合法解释的差异，
不能一律视作模型算错。原有 A/B/C 评测结果保持不变，不据此宣称准确率提升。
